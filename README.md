# ENPLY

**enp's playlist** — a single-file, responsive playlist web app.

- Live: https://e0ruv.github.io/enply/
- Everything lives in one `index.html`: home, explore, library, patch notes, synced lyrics view, and an admin tab for uploading audio, covers and `.lrc` lyrics.
- Uploaded tracks, covers and language choice are stored in the browser's `localStorage`, so nothing is sent to a server.
- Layout switches to a mobile pattern (bottom tab bar + mini player) below 980px.

Built with plain HTML/CSS/JS and Montserrat.
